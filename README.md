# Expense Tracker

A simple Python program to record and view daily expenses, saved in a CSV file.

## Features
- Add an expense with name, amount, and category
- View all expenses with the total spent
- Data is stored in expenses.csv

## Technologies
- Python 3
- CSV module

## How to run
1. Install Python 3
2. Download expense_tracker.py
3. Run: python expense_tracker.py
